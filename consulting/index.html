Case Study: Local AI in Production

Our deal sites, including Daily Lax Deals and Daily Coffee Deals, use a locally hosted language model to classify and score every product in the catalog, around the clock.

The problem

Thousands of products, constantly changing

Products from many stores need to be categorized and scored as deals every time they appear or change. Sending each one to a paid AI API would mean a recurring bill that grows with every site and every product.

The approach

Open-weight model on owned hardware

An open-weight model runs through Ollama on a Mac mini, as an always-on service that pulls work from a queue in batches. Scraping and classification are decoupled, so neither slows the other down.

Reliability

Guardrails and versioning

Rule-based checks correct known model mistakes. Each result is stamped with a version of the prompt, taxonomy, and model, so any improvement automatically re-queues the catalog, newest products first.

The result

Zero per-request AI cost

Continuous classification across multiple sites with no API bills, no rate limits, and no product data sent to a third party. Adding a new site is a configuration change, not a new AI budget.
